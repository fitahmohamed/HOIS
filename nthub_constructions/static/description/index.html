Overview in English

  • The system introduces an easy-to-use interface.
  • The system supports both Arabic and English Languages.
  • The system contains modern dashboard and reports.
  • Create Work Breakdown Template which have Materials, Labours, Expenses, Equipment and Subcontractor.
  • Create the project Contract for Construction Projects.
  • Add The contract down payment and You can Create an invoice for this.
  • You can add Extra Expenses and create an invoice from project Contract.
  • Create Work Breakdown Structure (WBS) for the Project.
  • The WBS generated is divided with project units and before creating you can choose unit (apartment,floor,building and unit).
  • Every WBS have the total cost for the chosen unit in details.
  • Create Completion request with finished quantity.
  • After confirming the completion request, If Partially accepted you will have a deduction amount added to the contract.
  • You can Make subcontracts from the Owner Contract.
  • Create subcontract delivery requests from subcontract.
  • After approval of the subcontractor acceptance requests, the amounts for this subcontracting are disbursed.
  • You can Combine subcontract delivery requests into one completion request.

الملخص باللغة العربية

  • يقدم النظام واجهة سهلة الاستخدام.

  • إنشاء قالب تفصيل العمل الذي يحتوي على المواد والعمال والمصروفات والمعدات والمقاول من الباطن.

  • يمكنك إضافة مصروفات إضافية وإنشاء فاتورة من عقد المشروع.
  • إنشاء هيكل تفكيك التكاليف (WBS) للمشروع.
  • يتم تقسيم WBS المنشأ مع وحدات المشروع وقبل الإنشاء يمكنك اختيار الوحدة (شقة ، طابق ، مبنى أو وحدة).

  • إنشاء ومتابعة المستخلصات وانشاء الفواتير الخاصة بها .
